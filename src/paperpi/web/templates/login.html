Forgot the password?

You need access to the Pi itself (a keyboard and screen, or SSH):

  1. Run sudo paperpi reset-password on the Pi. (Or remove the password_hash line in [web] of the config file, normally /etc/paperpi/paperpi.toml, by hand.)
  2. Restart PaperPi, or send it the reload signal: kill -HUP <process id> (sudo systemctl reload paperpi once it runs as a service).
  3. Open this page again and set a new password.

Until the new password is set, anyone on your home network can set it.
