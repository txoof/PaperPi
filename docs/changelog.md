# What's new

Every release of PaperPi has release notes on GitHub, with the changes it brings: **[PaperPi's releases](https://github.com/txoof/PaperPi/releases)**. The newest release is at the top.

## Which version do I have?

On the **Screen & system** page of the web interface, under **This Pi**, or at the bottom of every page. On the Pi, `paperpi --version` prints it.

## Getting the newest version

```bash
sudo paperpi-install update
```

PaperPi does not update by itself. More, and how to go back to an earlier version: [Update and remove](update.md).

## Version numbers

A version such as `2.0.0` is a full release. A version with letters, such as `2.0.0a1` or `2.0.0b1`, is a test release (alpha or beta): `update` installs it only while there is no full release yet.
